# ask-human-to-fetch

An [Agent Skill](https://agentskills.io) that gets a web page's content for your coding agent from a URL.

## Install

**Claude Code**

```
/plugin marketplace add lahmish/ask-human-to-fetch
/plugin install ask-human-to-fetch@lahmish
```

**Other agents:** copy `skills/ask-human-to-fetch/` to your agent's skills folder.

Requires Python 3.8+.

## Usage

Example prompt:

```
/ask-human-to-fetch example.com
```
